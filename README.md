# Todo List на React

Одностраничное приложение для управления задачами с синхронизацией через Todoist API. Поддерживает создание, редактирование, удаление задач, поиск, фильтрацию по тегам и приоритетам.

## Демо

[Открыть страницу](https://daryatash.github.io/todo-list-react/)

## Возможности

- Просмотр списка задач с загрузкой из Todoist
- Создание задач с описанием, дедлайном, приоритетом и тегами
- Отметка задач как выполненных
- Удаление задач
- Поиск по содержимому задач
- Детальный просмотр выбранной задачи
- Кнопка перехода к первой невыполненной задаче

## Технологии

- React
- TypeScript
- Vite
- React Hook Form
- Todoist API
- CSS Modules
